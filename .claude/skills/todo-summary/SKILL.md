# 오늘 완료 요약

데이터를 직접 열지 말고, 반드시 앱의 CLI로 읽는다.

1. 프로젝트 루트에서 `.venv/Scripts/python local-sqlite/todo_cli.py summary`를 실행한다.
2. 출력을 아래 커밋 메시지 형식으로 바꿔 코드 블록 하나로 보여 준다. 할 일 제목은 고치지 않고 그대로 쓴다.

   ```
   chore: 오늘(YYYY-MM-DD) 완료한 할 일 N건

   - <번호>. <제목> (<완료 시각>)
   - ...

   남은 할 일: M건
   ```

3. 오늘 완료가 0건이면 커밋 메시지를 만들지 말고 "오늘 완료한 할 일이 없습니다. 남은 할 일은 M건입니다."라고만 답한다.
4. 요약만 한다. `git commit`이나 `done`처럼 데이터·저장소를 바꾸는 명령은 실행하지 않는다.
